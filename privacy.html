LOCAL STORAGE ONLY

How it works.

Here is how data works in this web project.

⌑
No external tracking scripts

Your browser is the storage room.

Posts and your demo profile are saved in local storage on this device. Nothing is sent to a Commonplace server because this project does not have one.

Your controls

◷

Chronological feed

Posts appear newest first. There is no engagement ranking or recommendation model to switch off.

Always on
⊘

Third-party trackers

This codebase does not load analytics scripts, ad pixels, external fonts, or third-party APIs.

Not included
▤

Clear demo data

Remove posts, profile details, and the saved demo session from this browser.

i

A little honesty matters.

This is a practice project, not a secure production service. Local storage is readable by scripts running on the same origin and is not encrypted. Do not enter real passwords or sensitive information. A real privacy-first platform would also need security review, secure authentication, clear data policies, and careful hosting.
